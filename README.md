# Appliance Energy Cost

A Home Assistant custom integration that turns existing per-appliance cumulative
energy sensors and one all-inclusive dynamic price sensor into cumulative
money-cost sensors, priced at the price in force at the moment of consumption.
Everything runs locally through supported Home Assistant APIs — no cloud, no
accounts, no telemetry.

> **Status: early development — not yet functional.** The integration does not
> create any entities yet and has no working features. Do not install it
> expecting functionality.
